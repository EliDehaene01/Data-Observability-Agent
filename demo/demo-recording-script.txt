"One thing I'd improve next: today, the reconciliation checker has its
own separate, hand-maintained list of which exclusions are expected. When

GENERAL NOTES
-----------------------------------------------------------
- To edit a file via GitHub web UI: open the file -> click the pencil
  (edit) icon top-right -> make the change -> scroll down -> select
  "Create a new branch for this commit and start a pull request" ->
  name the branch -> "Propose changes" -> fill in PR title/description ->
  "Create pull request".
- Watch runs under the PR's "Checks" tab or the repo's "Actions" tab.
- Order matters: Scenario A MUST be merged before recording Scenario C.
  Scenario B does not depend on A being merged, but recording it after A
  (as scripted) keeps the story flowing naturally.
